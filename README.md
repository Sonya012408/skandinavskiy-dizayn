# Скандинавский дизайн: как сделать дом уютным

Разбор книги Кати Карлинг «Скандинавский дизайн: Как сделать дом уютным» (Альпина Паблишер, 223 стр.).

**Сайт:** https://sonya012408.github.io/skandinavskiy-dizayn/

**PDF:** [skandinavskiy-dizayn.pdf](skandinavskiy-dizayn.pdf) — 29 полос, вёрстка A4 с содержанием, колонтитулами, номерами страниц и закладками. Текст живой, не картинки.

## Что внутри

- **12 кейсов** — шесть реальных случаев из практики автора (клиентские проекты с исходной ситуацией, решением и выводом) и шесть предметов-эталонов, которые книга называет поимённо.
- **18 изображений** — акварели Карла Ларссона, портрет Эллен Кей, предметы скандинавского дизайна.
- **5 интерактивных демонстраций:**
  - сравнение «стокгольмского белого» NCS S 0502-Y и ярко-белого перетаскиваемым разделителем;
  - ползунок цветовой температуры 2000–5000 K, меняющий тон изображения;
  - переключатель схемы освещения: верхний свет против средней линии интерьера;
  - ползунок пропорции нового и винтажного — момент, когда доминанта перестаёт читаться;
  - чек-лист из 12 дел с сохранением отметок.
- **9 сквозных правил** книги.

## Ключевые числовые ориентиры из книги

| Параметр | Значение |
|---|---|
| «Стокгольмский белый» для стен | NCS **S 0502-Y** |
| Тёплый свет для жилых комнат | **2000–2700 K** |
| Нейтральный свет для работы | **4000 K** |
| Расстояние между источниками локального света | **~2 м** |
| Источников света в гостиной | **не менее 5** |
| Пропорция нового и винтажного | **80/20** или 70/30, но не 50/50 |
| Формат картины для стены средней высоты | **от 50 × 70 см** с рамой |
| Зазор навесного подоконника от стены | **3–4 см** |
| Глубина проникновения дневного света | **4–5 м** |
| Диаметр рождественской звезды в окно | **70–90 см** |

## Изображения и лицензии

Все изображения — из Wikimedia Commons. Акварели Карла Ларссона (Nationalmuseum) и портрет Эллен Кей кисти Ханны Паули — в общественном достоянии. Остальные под лицензиями CC0, CC BY и CC BY-SA. Авторство и лицензия указаны в подписи под каждым изображением на странице.

## Об источнике

Все идеи, цитаты, случаи из практики и числовые ориентиры принадлежат автору книги. Ни один пример на странице не добавлен со стороны — все предметы, люди и традиции названы в самой книге.

## Технически

Одностраничный сайт без сборки и зависимостей: единственный файл `index.html` со встроенными стилями и скриптами. Тёмная тема, адаптивная вёрстка, `prefers-reduced-motion`.

## Сборка PDF

Вёрстка — `print.html` (CSS Paged Media). Сборка — `build_pdf.py`: рендер через Chrome headless, затем автоматическое определение страниц для содержания, наложение колонтитулов и номеров через reportlab, закладки и сжатие через PyMuPDF.

```bash
python build_pdf.py
```

Изображения для PDF складываются в `assets/` (в репозиторий не входят — берутся из Wikimedia Commons).
